# Career Advisor Chatbot

## Project Description
The Career Advisor Chatbot is a Python-based chatbot applications that provides career-related guidance to users.
The chatbot is built using backend processing and API integration.

## Architecture
User → Streamlit Frontend → Python Backend → API Service → Response Output

## Setup Instructions
1. Clone the repository
2. Create virtual environment
3. Install dependencies using requirements.txt
4. Run the application using:
    Streamlit run app.py
